Label sizes and read distance
Roughly how far away each code can be read, for the size and style you picked (highlighted). Rules of thumb for a typical phone — light, angle and print quality move them, so test one label before printing a batch.

3 · Preview and print

How to print on a Dymo
In the print dialog pick your LabelWriter, set the paper to the matching Dymo label (part number in the size list), and print at Actual size / 100%, not "Fit to page". Each PDF page is exactly one label.
